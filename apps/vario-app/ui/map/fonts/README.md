# Map fonts

Glyph ranges (signed distance fields) of Noto Sans Regular, Bold and Italic for
MapLibre, covering Latin, Latin Extended, IPA/modifier letters and general
punctuation. Taken unchanged from <https://tiles.openfreemap.org/fonts/>
(built from <https://github.com/openmaptiles/fonts>).

Noto Sans is © Google and licensed under the SIL Open Font License 1.1
(<https://openfontlicense.org>).

To add a range, download `<font>/<start>-<end>.pbf` into the font's directory.
Ranges that are not bundled are answered with an empty glyph set by the app.
